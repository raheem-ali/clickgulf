# Clickgulf (Next.js 15, App Router, TypeScript)

    npm install
    npm run dev      # http://localhost:3000

- Edit services and hero slides: `lib/services.ts`
- Real hero photos: drop files in `public/images/` and set `image: "/images/xyz.jpg"` on the service
- Contact form delivery: `app/api/contact/route.ts` (add Resend / Nodemailer)
- Brand colours: top of `app/globals.css`
